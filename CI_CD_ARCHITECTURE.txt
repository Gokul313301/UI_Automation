WHAT GETS CAPTURED:
===================

1. LOGS
   ├── build_TIMESTAMP.log
   │   └── Build initialization, git info
   ├── docker_build_TIMESTAMP.log
   │   └── Docker image build output
   ├── test_execution_TIMESTAMP.log
   │   └── Every step definition execution
   ├── allure_TIMESTAMP.log
   │   └── Allure report generation
   └── failure_report_TIMESTAMP.log
       └── Details of failed tests

2. SCREENSHOTS (On Failure)
   ├── login_invalid_password_failure.png
   ├── checkout_total_mismatch_failure.png
   └── ... (one per failed test)

3. TEST REPORTS
   ├── surefire-reports/TEST-*.xml
   │   └── JUnit format (Jenkins reads this)
   └── allure-results/*.json
       └── Allure format (detailed test data)

4. ALLURE RESULTS
   └── Converted to HTML with:
       ├── Screenshots embedded
       ├── Execution timeline
       ├── Test history
       ├── Test categorization
       └── Interactive dashboards


KEY FEATURES:
=============

✓ BRANCH TRIGGER
  - Any push to any branch triggers build
  - Uses parameters if manual trigger

✓ TAG TRIGGER
  - Tag push triggers build
  - Useful for release testing
  Example: git tag v1.0.0 && git push origin v1.0.0

✓ PARAMETERIZED
  - Environment selection: qa, dev, staging, prod
  - Browser selection: chromium, firefox, webkit
  - Headless mode: true/false
  - Test tag filter: @smoke, @regression, @sanity

✓ CONTAINERIZED
  - Docker ensures consistent environment
  - Same behavior local vs CI
  - Easy scale with multiple Jenkins agents

✓ SCREENSHOT CAPTURE
  - Automatic on test failure
  - Embedded in Allure report
  - Easy visual debugging

✓ COMPREHENSIVE LOGGING
  - Every step logged
  - Docker output captured
  - Build process transparent

✓ EMAIL NOTIFICATIONS
  - Sent on test failure
  - Includes clickable links
  - Sent to relevant people

✓ ALLURE REPORTS
  - Rich visual reports
  - Interactive UI
  - History tracking
  - Screenshots embedded

✓ PARALLEL EXECUTION
  - 4 tests run simultaneously (configurable)
  - Reduces build time
  - Configured in junit-platform.properties

TROUBLESHOOTING:
================

Build won't trigger?
  → Check webhook in GitHub/GitLab settings
  → Verify response code is 200

Docker build fails?
  → Run manually: docker build -t test:dev .
  → Check Docker logs for missing dependencies

Tests timeout?
  → Increase timeout in Jenkinsfile
  → Check if tests are slow locally too

No screenshots captured?
  → Verify @After hook in Hooks.java
  → Check test is actually failing

Allure report empty?
  → Check allure-results/ has .json files
  → Run: docker exec container ls /app/allure-results/

Email not sent?
  → Check email config in Manage Jenkins → Configure System
  → Verify SMTP credentials
